Invoke the write-stakeholder skill. Writes stakeholder requirements for an existing BRD into a separate file, docs/brd/[change-name]-SR.md — operational accountabilities, high-level business rules, business policies and compliance mandates — written system-neutral so each passes the paper process test. Each row follows the declarative blueprint (entity + is/are/retains/provides/is accountable for + condition + to ensure/so that + outcome), with no modals, sits under business capability and process-step headings, and carries an SR-[DOMAIN]-[PROCESS]-NNN ID and a MoSCoW priority. Rules and attribute lists are referenced by versioned anchors or baseline appendix tables, never inline. Statements it declines are recorded in a routing register, and §9 Traceability is filled in both directions. Reads the BRD and never edits it; the file carries the BRD's Doc ID and is written behind a confirmation gate. Use when a BRD from /write-brd-v2 needs its stakeholder requirements, or when /write-stakeholder is run.
