Invoke the review-language skill. Checks the wording of a requirements document — BRD, PRD, ORD or AC — against the requirements language standard (`language.md`), including the modal and construction bans and the rules adopted from the Australian Government Style Manual: voice and tone, sentence length, plain words, numbers, dates and units, punctuation, locale and citation form. Classifies each section first so quotations, fixed labels and recorded deviations draw no false findings, then reports every finding graded Defect or Advisory with its location, the rule it breaks and a suggested rewrite that never invents a value. Advisory: changes nothing in the document and emits no score. Also runs automatically as the advisory language pass inside /review-ord and /review-brd. Pass the document as a file path or in the conversation. With `--skill <name>`, checks only the templates, placeholder text and worked examples inside that skill's folder — never its instruction prose — so a template that still teaches an old form is found after `language.md` changes. Use before a requirements document is shared or handed off.
