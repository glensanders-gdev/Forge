Invoke the review-resume skill. Assesses an existing resume, CV or cover letter through its three readers: the ATS parser (text layer, reading order, headings, dates, hidden text), the LLM screener (a summary test of what a model would extract, evidence-in-context, quantified impact, job-ad terminology) and the human recruiter (bullet quality, specific language, market conventions such as Australian length and referees, cover letter evidence and fit). Reports per-item verdicts with no match score, ranked fixes and before → after rewrites, then, once the user approves, writes a revised parse-safe version that invents no facts and marks missing metrics as placeholders. Optionally pass a target job ad for a requirement-by-requirement gap analysis. Pass the document as a file path or pasted text. Use when the user provides a resume, CV or cover letter for review or improvement.
