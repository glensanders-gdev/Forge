Invoke the write-agent-brief skill. Turn an existing PRD, ticket or set of requirements, or the decisions agreed in this conversation or in pasted notes or a transcript, into an agent brief that an AI agent can act on cold: goal, definition of done, testable acceptance criteria, constraints with their reasons, scope bounds and stop conditions, a verification check, and the questions to ask rather than assume. Puts every gap in the source to you rather than filling it. From a conversation, only what you stated or plainly agreed becomes a requirement, and unconfirmed suggestions become questions. Stops if a document has no goal or definition of done; for a conversation, asks for them once first. Writes to docs/briefs/[slug].md for a repo agent, or returns a paste-ready block for a chat assistant such as Microsoft 365 Copilot. Optional arguments: the source path or ticket (omit it to brief from this conversation), and the target (e.g. /write-agent-brief docs/prd/active/login.md --target repo). Use when you are about to hand requirements to a coding agent, sub-agent or chat assistant.
